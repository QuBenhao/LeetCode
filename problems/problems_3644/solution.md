> question: Maximum K to Sort a Permutation (maximum-k-to-sort-a-permutation)

> Problem: [3644. 排序排列](https://leetcode.cn/problems/maximum-k-to-sort-a-permutation/description/)

## 结论

记 `M` 为所有**错位**元素的值（`nums[i] != i` 的那些 `nums[i]`），则

```text
answer = AND(M)          # 全部在原位时答案为 0
```

一遍扫描即可，`O(n)` 时间、`O(1)` 空间。

## 一、上界：k 必须是每个错位值的子掩码

错位的值 `x` 至少要参与一次交换（它得离开当前位置），而一次交换 `(x, y)` 允许的前提是 `x & y == k`，这要求 `k` 的每一位都在 `x` 里，即 `k ⊆ x`。

于是 `k ⊆ AND(M)`，也就是 `k ≤ AND(M)`。这是约束的**唯一**来源，且只用到「每个错位值至少被换一次」这一点。

## 二、可达：一个万能枢纽就够

关键引理：**若存在值 `b`，对所有错位值 `x` 都有 `b & x == k`，则错位值上的任意置换都能实现**（`b` 是「缓冲元素」）。互换两个目标 `a`、`c` 的做法：

```text
b↔a, b↔c, b↔a, b↔c      # a、c 互换，b 回到原位
```

每一步都只涉及 `b` 和一个目标值，所以每一步都合法。能实现任意置换，自然也就能排序。

取 `k = K = AND(M)` 时枢纽一定存在：

- `K > 0`：按定义 `K ⊆ 每个错位值`，所以 `K & x == K`，**值 K 自己**就是枢纽；
- `K = 0`：`0 & x == 0`，值 `0` 就是枢纽。

这里有个容易被忽略的点：枢纽必须**真的存在于数组中**。题目给的是排列，值域恰好是 `[0, n-1]`，而 `K` 落在这个范围内，所以 `K` 必然作为某个元素出现——这条性质是「上界可达」的必要条件，不是无关的输入限制。

## 三、为什么不需要按环/连通块分解

自然的想法是把置换拆成环，逐环检查「环内元素能不能互相换通」。这样做不会错，但结论会退化成同一件事：排列的每个环，其**位置集合等于值集合**，于是

```text
AND over 环内 i (nums[i] & i) = AND(环值) & AND(环位置) = AND(环)
```

逐环再与起来就是全局的 `AND(M)`。

更关键的是，「环内两两可换」这个要求本身**过强**。例如 `nums = [0,1,2,5,4,7,6,3]`（环 `3→5→7→3`，`K = 5&7&3 = 1`）：环内三对里只有 `3&5 == 1` 成立，`3&7 == 3`、`5&7 == 5` 都不等于 1，但答案是 1——不动点上的值 `1` 正好是枢纽（`1&3 = 1&5 = 1&7 = 1`）。连通性只要「全体挂在一个枢纽上」，不必两两相邻。

## 四、示例

```text
[0,3,2,1]  错位值 {3,1}      → 3&1     = 1
[0,1,3,2]  错位值 {3,2}      → 3&2     = 2
[3,2,1,0]  错位值 {3,2,1,0}  → 3&2&1&0 = 0
```

## 代码

```python
class Solution:
    def sortPermutation(self, nums: List[int]) -> int:
        ans = -1
        for i, x in enumerate(nums):
            if x != i:
                ans &= x
        return 0 if ans < 0 else ans
```

`ans = -1` 在 Python 里等价于「无限多个前导 1」，是与运算的单位元（`-1 & x == x` 恒成立），所以不必先算位宽。它同时兼当哨兵：真实的 AND 结果永远非负，`ans < 0` 当且仅当循环一次都没进过，也就是数组本来就有序。

## 复杂度

- 时间 `O(n)`：一次扫描；
- 空间 `O(1)`：只用一个累加器。

## 两个实现细节

1. 不要用 `(1 << n.bit_length()) - 1` 这类掩码当单位元：它要靠「`nums[i] < n < 2^bit_length`」保证位宽够用，写窄了会静默截断（`0b111 & 10 == 2`）。`-1` 不需要这个证明。
2. 匹配条件是**恰好等于** `k`，但这只影响「两个值能否直接交换」，不影响结论：排序只需要枢纽存在，不需要每对都满足。
